# Home dashboard layout

Reorganised the shared guest/signed-in home screen into an asymmetric dashboard:

- A clear welcome heading and direct progress link.
- A large next-step card beside a dedicated rank card with a bold title, larger sigil and XP progress.
- A two-by-two grid of labelled study, lesson, practice and timed-practice shortcuts near the top.
- A weekly-plan panel beside stacked daily-challenge and target-progress cards.
- Subject progress and lifetime statistics remain available below.
- Optional placement, story and account prompts follow the primary tools.

Body copy uses the existing accessible sans-serif preference, larger text and stronger secondary text colours. Long plan titles wrap. Cards use opaque theme surfaces so background art does not compete with labels. Narrow screens stack the main panels and retain a compact two-column shortcut grid. The existing font-size preference still scales all text through the project's CSS pipeline.

No changes to question content, account state, scores, rewards or navigation destinations. Build and existing tests run before publication. Device-level and authenticated visual verification are not claimed by this log.
